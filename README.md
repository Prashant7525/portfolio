# Personal Portfolio

A modern portfolio website built using Next.js, React, Tailwind CSS and TypeScript.

## Live Demo
https://prashant7525.vercel.app

## Features
- Responsive Design
- Hero Section
- About Section
- Skills
- Projects
- Resume Download
- Contact Section

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- Vercel

## Run Locally

npm install

npm run dev
